# Solar 0.15.3 — périmètre produit

Application macOS et Windows open source de conversation avec une équipe d’agents. Chaque profil possède son nom, sa forme, sa couleur, sa mission, son historique et son niveau d’accès. Les managers occupent la zone supérieure et les profils se déplacent directement dans la barre latérale.

Le choix du moteur est explicite : détection Ollama, clé OpenAI personnelle ou Solar Cloud quand configuré. L’inférence locale ne rend pas les connecteurs hors ligne. Aucune clé privée n’est distribuée avec le code ou le DMG public.

La conversation présente des messages successifs, des questions contextuelles et les opérations réellement exécutées. Les paramètres d’apparence, brouillons, pièces jointes et autorisations restent conservés. La bibliothèque contient les dossiers ajoutés par l’utilisateur. Ordinateur est annoncé Bientôt.

La version 0.15.3 fournit un DMG Apple Silicon signé ad hoc, non notarisé, et un installateur NSIS Windows x64 sans certificat éditeur. Les services optionnels doivent être configurés. Le stockage local n’est pas une synchronisation ou sauvegarde cloud complète.
