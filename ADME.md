# Solar

Solar is a local-first macOS desktop foundation for a multi-provider AI chat application.

## Development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:1420` for the temporary browser preview.

For the native macOS app (after Rust/Xcode are installed):

```bash
npm run tauri dev
```

See `SOLAR_SPEC.md`, `ARCHITECTURE.md`, `ROADMAP.md` and `PROGRESS.md`.
